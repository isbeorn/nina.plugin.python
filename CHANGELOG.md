# Python Scripting

## 1.0.0.2
- Inject in-scope N.I.N.A. sequencer variables into Python script scopes as a `variables` mapping, direct read-only `Var_name` aliases, and the `setVariable` write helper.
- Add `getSymbolProvider(name)` to get or register a custom symbol provider from Python scripts.

## 1.0.0.1
- Inject N.I.N.A. symbol broker values and functions into Python script scopes as read-only variables, callable functions, and read-only `symbols` / `symbolFunctions` mappings.
